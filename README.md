# The Web-ex Project
This repository is for students only that wants to learn on how to code or develop using Hyper-Text Markup Language, Cascading Style Sheet, JavaScript, Node.js, Python, Hypertext Preprocessor and other languages necessary for making their own website or web app.

For learning how to code first, go to [my website](https://web-ex.netlify.app) to find the lessons you need to understand and find a worksheet to finally test your knowledge. The worksheet can be used before for a self-service pre-test and [email me here for the answer key.](mailto:paminecraftlover@gmail.com) You can use the given answer key if you will take the worksheet again for a self-service post-test.
